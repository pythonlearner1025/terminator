# KF2 study sources

Reference images are for study only. They are excluded from publication.
No copied KF2 image or model appears in assets.

YouTube searches used yt-dlp. Clips used video-only formats at 480p or lower.
The installed March downloader returned media HTTP 403 errors.
The August 2026 downloader recovered the clips.
ffmpeg produced 640-pixel JPEGs. No browser opened.
